# Image plugin release checklist

Version 0.4.4 is a signed release candidate; it has not been uploaded to Marketplace.

## Transfer and shell regression fixed in 0.4.1

Reproduced `Failed to fetch` in actual PyCharm JCEF: the same 43 MB PFM
response succeeds with `arrayBuffer()` and fails with `blob()`. File delivery
now reads bytes directly. This is a host transfer failure, not a format decoder
failure. The IDE mounts a minimal Svelte shell from the outset; the website
landing page, toolbar, URL dialog and legal navigation are never mounted.

Actual JCEF regression passes for large PFM and TIFF (3600×3000), NPY and EXR
(5120×5120), and 16-bit PNG. A MutationObserver checks that website shell nodes
never appear during initial load. Website host checks and five browser tests
covering image loading, tabs and home navigation also pass.

Reproduce with the isolated IDE open:
`JAVA_HOME=/path/to/jdk node jetbrains/scripts/check-jcef-transfer.mjs /path/to/sample.pfm /path/to/sample.npy`

## Artifacts and reproduction

Signed ZIP: `build/distributions/scientific-image-visualizer-jetbrains-0.4.1-signed.zip`.
Reports: `build/reports/pluginVerifier`; screenshots/exports: `build/release-evidence`.

```sh
./gradlew test buildPlugin verifyPlugin -PverificationIde=/Applications/PyCharm.app
./gradlew signPlugin verifyPluginSignature -PsigningDirectory=/private/signing-directory
node scripts/smoke-viewers.mjs ../test-samples/house.tif ../test-samples/png_u16_gray.png
# With the isolated test IDE already running on its development debugging port:
cd ..
node jetbrains/scripts/check-live-ide.mjs
```

Alternatively configure JETBRAINS_CERTIFICATE_CHAIN, JETBRAINS_PRIVATE_KEY and
optional JETBRAINS_PRIVATE_KEY_PASSWORD. Ordinary builds never upload.
Remove the old combined prototype before installing. The independent 3D plugin
can remain installed. Editor settings are not restored after closing/reopening.

## Gesture tuning in 0.4.2

Mac pan conversion reduced from 40 to 8 pixels per precise wheel unit as an
initial calibration following excessive-travel feedback. Embedded wheel zoom
now shares the VS Code step response; website zoom remains continuous and
native macOS magnification remains proportional. `node test/ide-zoom-parity-test.cjs`
checks equivalent wheel inputs across the IDE hosts. Physical trackpad feedback
is still required to assess subjective speed and momentum. Signed 0.4.2 is
installed in the isolated current-IDE test profile.

## CZI navigation correction in 0.4.3

Requested plane controls update immediately while decoding; superseded results
no longer overwrite newer selections. The shared navigation renderer clears
the loading class on completion. Slow-worker browser regression and actual
PyCharm JCEF rapid-arrow checks pass with synthetic-stack.czi. Type checking,
Java tests, signing and signature verification pass. User confirmed 0.4.2
physical gesture feel; recheck their real CZI file in the installed 0.4.3 test build.

## Continuous CZI previews in 0.4.4

Completed planes are now rendered before the queued request starts. Requested
controls remain independent from the decoded plane. This replaces 0.4.3’s
intermediate-result discard, which could starve previews during continuous input.
The slow-worker browser regression requires multiple canvas updates while arrow
input is still active, then verifies the final requested position and loading reset.
