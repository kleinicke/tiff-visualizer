Quick start · about 2 minutes

Open an image and see what its pixels contain

Start with a sample image. You can inspect values, change how the image is displayed, and then open your own scientific data.

Try the viewer

Try it with a sample

  1. Open the viewer and select Microscopy under Try an example. It loads a multi-slice TIFF with two channels.
  2. Zoom with the mouse wheel or trackpad, drag to pan, and hover over the image to see its pixel readout.
  3. Use the image navigation controls to change slice or channel. Open Options in the bottom bar for the histogram, metadata and measurement tools.

Open your own image

Choose Open files or drop files onto the page. Local files stay on your device. To inspect a public image, choose Open URL and paste its link; the image host must permit cross-origin browser access.

The viewer handles TIFF/OME-TIFF, microscopy formats such as CZI and ND2, DICOM, FITS, NetCDF, NPY/NPZ, EXR, PFM and common image formats. See the format reference for compression and bit-depth details.

If an image appears all black or white

A floating-point image can contain valid values outside the default display range. The bottom bar has Auto-Norm, gamma and exposure controls. Start with Auto-Norm; then open the histogram from Options to see the value distribution. These controls change the display, not the source file.

What next?

  • Compare images: open more than one file and use the tabs or layers tools.
  • Measure a region: open Options → Measure and choose a shape.
  • Need more detail? Read the getting started documentation.
